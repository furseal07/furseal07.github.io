02 About me

문제를 발견하는 시각에
구현력을 더했습니다.

운영 현장에서 발견한 문제를 데이터 흐름과 코드로 해결하는 Java 풀스택 개발자입니다.

4년 이상 소셜 데이터 정제, AI 학습 데이터 검수, 검색·광고 품질 관리를 수행하며 서비스의 결과는 데이터 기준과 일관성에서 시작된다는 점을 배웠습니다. 반복 업무를 AutoHotkey로 자동화하고, 오늘의집에서는 Taxonomy 정비와 토픽 분류 모델 구축을 지원해 추천 탭 구매 전환율 3% 향상에 기여했습니다.

문제를 발견하는 데서 그치지 않고 해결 구조를 직접 만들고 싶어 컴퓨터과학을 공부하고 1,120시간의 Java 클라우드 풀스택 교육을 이수했습니다. 기능을 빠르게 추가하는 것보다 업무 규칙과 데이터 관계를 먼저 이해하고, 예외 상황에서도 일관된 흐름을 만드는 데 집중합니다.

협업할 때는 요구사항과 공통 기준을 먼저 문서화하고 우선순위와 진행 상황을 공유합니다. 수천 건의 데이터를 검수하며 기른 꼼꼼함에 일정과 협업을 함께 고려하는 방식을 더했습니다.
